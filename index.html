Research · LLMs for security

Automated security patch generation with semantic hints

Can a small specialist model help a code LLM fix vulnerabilities? I built a pipeline where CodeAstra-7B writes a short hint about each vulnerability, then CodeLlama-7B patches the code with and without that hint. Each patch is scored for security, whether it still compiles and runs, and how close it is to the expert fix.

Juliet C/C++→CodeAstra hints→CodeLlama patches→flawfinder · gcc · CodeBERT
